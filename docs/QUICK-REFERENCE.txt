```powershell
# Terminal 1: Kill old processes
Get-Process node -ErrorAction SilentlyContinue | Stop-Process -Force
Start-Sleep -Seconds 2

# Terminal 1: Start backend
cd backend
npm start
# Wait for: "Express server running on port 5000"

# Terminal 2: Start frontend
cd frontend
npm run dev
# Wait for: "Local: http://localhost:3001/"
```

## 🔍 TROUBLESHOOT 401 ERROR
```
F12 → Network tab:
  ✅ OPTIONS request → 204 (not 403)
  ✅ POST request → 200 (not 401)
  ✅ Response header: access-control-allow-origin: http://localhost:3001

F12 → Application:
  ✅ localStorage.auth_token exists
  ✅ Cookies.session_token exists (HttpOnly)

F12 → Console:
  No red error messages
```
